### Maintainer notes

omafile is a native GTK 4 / libadwaita file manager for Omarchy plus this bar-widget plugin. The widget (plugin/BarWidget.qml) only runs `omafile`, `omarchy-launch-or-focus` and `omafile --lock-all` through bar.run and reads ~/.local/state/omafile/status for its marker. The file manager binary itself is installed separately (install.sh or PKGBUILD, see README); the plugin never writes user configuration. External dependencies are listed in the README under "Requirements".
